# 一年级学习工作台

纯前端（无后端、无数据库）的一年级每日学习工作台，语数英全科。

在线使用：直接打开 Pages 地址；手机浏览器菜单 →「添加到主屏幕」，可当 App 用（支持离线）。

## 内容
- 语文：古诗 21 首、成语故事 20 个、识字 140 字（全部带笔顺动画）、拼音 48 组看图拼读、阅读打卡书单
- 数学：10/20/100 以内口算 5 档 + 60 秒限时挑战、数感游戏、认识钟表、认识人民币、每日思维题、错题本
- 英语：每日 5 句 + 5 词，98 词汇 / 49 句型，点读发音
- 运动：一周 7 天计划（对齐一年级体测）
- 打卡积分、成长报告

## 本地打开
双击 index.html 即可（Chrome / Edge）。

## 目录
```
index.html              入口
css/style.css           样式
js/data-*.js            内容库（改这里即可换内容）
js/store.js             进度/积分存储（localStorage）
js/app.js               页面与交互
js/strokes-data.js      汉字笔顺数据（已内置，离线可用）
sw.js / manifest.webmanifest  PWA 离线与主屏幕
```
