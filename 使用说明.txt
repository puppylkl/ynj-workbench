一年级学习工作台 v1 —— 使用说明
=====================================

【这是什么】
一个纯网页版的「一年级每日学习工作台」，由「幼小衔接工作台」改造而来，
内容按一年级课程重新编排：语文 / 数学 / 英语 / 运动 / 游戏 / 打卡积分 / 成长报告。

【怎么打开】
方法一（电脑）：双击 index.html，用 Chrome / Edge 打开即可。
方法二（手机/平板）：把整个文件夹放到手机里，用浏览器打开 index.html；
                 或放到任意静态网页空间（如 GitHub Pages）后访问网址，
                 再在浏览器菜单里选「添加到主屏幕」，就像 App 一样用。
方法三（局域网）：电脑上执行 python -m http.server 8777，
                手机连同一个 WiFi，访问 http://电脑IP:8777

【内容说明】
· 语文：古诗 21 首（部编版一上一下 + 经典启蒙，带拼音和译文）
        成语小故事 20 个（寓言类，浅显易懂）
        识字 140 字（部编版一上写字表 96 字 + 一下核心 44 字，每天 3 个新字 + 复习）
        笔顺动画：140 个生字全部可以看笔顺演示，还能手动输入其他汉字查笔顺
        拼音：23 声母 / 24 韵母 / 16 整体认读 + 48 个看图拼读词
        阅读打卡：含「快乐读书吧」推荐书单
· 数学：口算 5 种难度（10 以内 / 20 以内进退位 / 100 以内加减 / 连加连减 / 混合）
        60 秒限时口算挑战（一年级口算达标训练）
        数感小游戏：数一数、比大小、数的组成、找规律、相邻数
        认识钟表（整时、半时）、认识人民币（元角分换算、找零）
        每日 2 道思维题、错题本自动收集
· 英语：每日 5 句 + 5 词，共 98 个词汇、49 个句型（问候/课堂/颜色/数字/动物/家庭/食物…），点喇叭可发音
· 运动：一周 7 天运动计划，兼顾一年级体质测试项目（跳绳、坐位体前屈、50 米跑、立定跳远）
· 积分打卡：完成必做任务得积分，可兑换奖励（奖励内容在「设置」里自行修改）

【家长可自定义】
· 设置 → 任务管理：增删改每日任务（比如加上「练琴」「口算卡」）
· 设置 → 奖励管理：改成孩子喜欢的奖励
· 设置 → 数据备份：导出／导入进度，换设备不丢
· 学习进度、积分、错题都存在本机浏览器里，不上传任何服务器

【如何调整内容库】
所有内容都在 js 目录下，纯文本可改：
  js/data-poems.js    古诗
  js/data-idioms.js   成语
  js/data-hanzi.js    生字（c=汉字 py=拼音 mean=意思 word=组词）
  js/data-pinyin.js   拼音与看图拼读
  js/data-english.js  英语词汇与句型
  js/data-misc.js     思维题、运动计划、书单
改完保存，刷新网页即生效。

【注意】
· 汉字笔顺数据（js/strokes-data.js）已内置，无需联网；
· 语音朗读用系统自带的朗读引擎，英文发音质量取决于电脑/手机系统语音包。
